## House decisions, with their evidence

| Decision | Why |
|---|---|
| **The main session is the orchestrator.** There is no orchestrator agent. | With an orchestrator agent, code review sat at depth 3, the deepest the default allows, so one lower limit broke it. That agent could not ask the user anything mid-run, and it could not call the currency companion as a skill. Now `code-reviewer` is at depth 1 and its specialists at depth 2; the preflight and the currency sweep are real questions and real skill calls; and every piece of state is in a run folder, so `resume` works after a compaction. |
| **An agent tree, not a dynamic workflow.** | Dynamic workflows re-run and resume well, and they pause and continue at a usage limit (2.1.271). But a workflow takes "No mid-run user input", and this audit asks at preflight and may run the currency sweep mid-way. A user may also have workflows switched off, and nested dispatch inside a workflow is unproven here. **Revisit** if real runs end PARTIAL on usage limits twice, or once workflows can take a question mid-run. Source: https://code.claude.com/docs/en/workflows |
| **No headless mode, at all.** | A headless session runs unattended and is billed apart from the interactive session. Every agent here runs inside the interactive session, under its permission prompts, and no step of this skill starts a headless session. |
| **Stable IDs from `check` + `subject` + first evidence path.** Prose is never part of the fingerprint, and IDs are reused from the previous run's `findings.json`. | A hash of the model's own sentence changes whenever the same finding is reworded, and a short hash collides. The fingerprint uses only what the finding is about, and `findings.json` keeps it, so `diff` and `/apply-rec` can rely on it. |
| **Local agents have no shell; the researcher has no local read.** | An agent that holds local shell access and web search at once can be steered by a poisoned page into putting local data into a search query. So no agent holds both, and the facts a local agent would need a shell for come from `config-facts`. |
| **Replies are saved from transcripts (`save-result`), never pasted.** | The companion package observed this in real sweeps: notification text is HTML-escaped by the harness, and one long reply was split in two by the output limit. The transcript holds the agent's own bytes. |
| **The cost estimate lives in the mandatory preflight, not in a hook.** | A `UserPromptSubmit` hook ignores matchers, so a budget hook there fires on every prompt, and it must parse the prompt to guess the scope. The preflight already knows the plan and already asks, so the estimate goes there. A hook whose matcher its event ignores is what checklist C2 looks for. |
| **One URL policy for every fetch.** Each lead URL, and the page a fetch finally lands on, must be https with a public host: no user-info, no trailing dot or single-label name, no local suffix, and no IP literal in any spelling (short, integer, hex or octal forms included) unless it is a canonical, global address. | Server-side request forgery: a fetcher steered to `localhost`, a private range or a cloud metadata address. OWASP, Server-Side Request Forgery Prevention Cheat Sheet: https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html . Known limits, accepted: names are not resolved (TLS certificate verification is the remaining guard against a public name pointing inward), and intermediate redirect hops are https-only but not host-checked. |
| **The helper's python starts isolated (`-I`).** | Python puts the working folder first on its module path, so a file such as `json.py` in an audited folder would otherwise be imported and run. `-I` drops that entry and ignores `PYTHON*` variables: https://docs.python.org/3/using/cmdline.html#cmdoption-I |
| **Research leads never change a severity.** | A lead is context for the person who triages, verified by re-fetching the quote. The agent that read the code owns the judgment, and a web page does not get to overrule it. |
| **Insights cap at `medium`.** | Ideas and defects share the severity counts. Capping the ideas keeps "critical" and "high" meaning "broken". |
| **The helper owns the arithmetic.** Module sizes are true totals, report numbers sort as numbers, and report globs match reports only. | Each is easy to get wrong by hand: one file's line count taken as a module's size, `v10` sorted before `v9` as text, an error or progress file matched as a report. All three are regression cases in the helper suite. |

## Deliberate deviations

- **superpowers:writing-skills suggests a flat skill folder; this package does not follow that.** `resources/` holds the depth (references, a testing guide, a worked example, an example report), which a reader loads only when needed.
- **Decision record.** This file carries the design decisions; the package has no separate decision log.
